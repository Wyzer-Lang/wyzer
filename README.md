Wyzer will undergo with it's 3rd rewrite with a newer memory model
## The Wyzer Programming Language
Wyzer is a statically typed, compiled, resource-oriented programming language with integrated distributed safety via choreographic programming and a perceus memory model.


## Goals of the research (SORM memory model)
- memory safety which is established at compile time
- distributed deadlock safety, protocol agreement and cross-service correctness
- ease of use, somewhat close to reference counting or a garbage collector
- low runtime cost
- safe metaprogramming
